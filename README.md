# The Portrait Edit

## Issue 02 - The Prompt Issue, revised

[Open the revised magazine](revised/The_Portrait_Edit_Issue_02_Revised.pdf)

196 letter-size pages organize all 174 unchanged image prompts into nine themed chapters. Each study keeps its original reference image, title, number, Source filename, and working notes, with an additional note-based “Try this” line. The issue adds a two-page glossary, chapter contents and openers, PDF bookmarks, duplicate notes, and editorial review labels.

[Audit](revised/audit.md) · [Chapter mapping](revised/chapters.json) · [Changes and full audit](revised/CHANGES.md) · [Rebuild instructions](revised/README.md) · [Build script](scripts/build_issue_02.py)

![Revised cover](revised/sample-cover.png)

All source pixels are retained without cropping or upsampling. Six existing mismatches receive “Review pairing”; images have not been swapped. All portrait references receive “Rights check” for publisher review, without identity or licensing claims. Duplicate and near-duplicate pages remain.

Validation confirms exact normalized prompt and note preservation, all 174 studies once in the contents, original filenames, correct contents links, image dimensions, and text bounds. The cover, chapter opener and study-page samples were inspected visually.
